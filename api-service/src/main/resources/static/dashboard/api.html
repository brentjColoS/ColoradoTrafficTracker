Dashboard API

The same bounded JSON endpoints that power the dashboard are available for inspection and small integrations.

Access model

Public dashboard reads use the /dashboard-api prefix. The corresponding /api routes are intended for authenticated access when API security is enabled.

All endpoints are read-only. Time fields use ISO 8601 UTC values. Historical queries include retained archive rows where that dataset supports them.

Bounded by design

History endpoints require a corridor and bounded window or result limit. Supported corridor values are I25 and I70.

These reads do not trigger new TomTom or CDOT requests; they query observations already retained by the application.

Useful endpoints

/dashboard-api/traffic/latest?corridor=I25&preferUsable=true

Latest retained corridor sample, preferring a usable flow observation.

/dashboard-api/traffic/history?corridor=I25&windowMinutes=120&limit=180

Bounded corridor sample history.

/dashboard-api/traffic/summary?corridor=I25

Current sample, recent analytics, provider state, and incident summary.

/dashboard-api/traffic/analytics/trends?corridor=I25&windowHours=24

Time-bucketed corridor trend data.

/dashboard-api/traffic/zones/trends?corridor=I70&windowHours=168

Bounded speed-zone history with every configured zone preserved.

/dashboard-api/traffic/zones/baselines?corridor=I70

Weekly refreshed, three-month reference profiles for every configured speed zone.

/dashboard-api/traffic/map/corridors

Tracked corridor geometry and mile-marker calibration.

/dashboard-api/traffic/map/incidents/recent?corridor=I25&windowMinutes=120

Durable incident events overlapping a selected recent window.

/dashboard-api/traffic/map/flow-cells/current?corridor=I25

Latest coherent combined-direction map cells.

/dashboard-api/system/operational-status

Overall service state with component-level reasons and next actions.

/dashboard-api/system/provider-status

TomTom guard state and separate account-capacity details.

Response expectations

  • A successful empty or unavailable result can be represented by an empty collection or HTTP 404, depending on the endpoint.
  • HTTP 400 means the corridor, window, timestamp, or limit was outside the endpoint contract.
  • Public reads may be rate limited and cached. Clients should avoid tight polling loops.
  • Provider credentials and private operational configuration are never part of these responses.

Source, DTOs, and endpoint validation are available in the API service repository.
