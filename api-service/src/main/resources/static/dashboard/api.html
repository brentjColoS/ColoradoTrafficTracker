Endpoint catalog

Start with the question, not the controller

The common reads are grouped by what they help answer.

What is happening now?Current traffic and system state
GET /traffic/latest

Latest corridor sample, optionally preferring usable flow.

GET /traffic/summary

Current sample, recent analytics, provider state and incident context.

GET /system/operational-status

Overall service state with component reasons and next actions.

GET /system/provider-status

TomTom guard state and account-capacity detail.

How has traffic changed?History, zones and comparison patterns
GET /traffic/history

Bounded corridor sample history with optional incident payloads.

GET /traffic/analytics/trends

Time-bucketed current and historical corridor trend data.

GET /traffic/zones/trends

Bounded history for every configured speed zone.

GET /dashboard-api/traffic/zones/baselines?corridor=I70

Weekly refreshed three-month reference profiles by zone.

Where is it happening?Geometry, incidents and road sections
GET /traffic/map/corridors

Tracked corridor geometry and mile-marker calibration.

GET /traffic/map/incidents/recent

Durable events overlapping a bounded recent window.

GET /traffic/map/flow-cells/current

Latest coherent combined-direction half-mile traffic cells.

GET /traffic/map/flow-cells/frequency

Slowdown frequency for supported long-range windows.

Routes above omit the access prefix. Use /dashboard-api for public dashboard reads or /api for authenticated access when API security is enabled.

Access model

Two doors, one read service

The route changes access policy, not the meaning of the response.

Public dashboard reads/dashboard-api

Available when public dashboard data is enabled.

API servicecurrent + archive-inclusive queries
Authenticated clients/api

Requires a valid X-API-Key when security is enabled.

Response contract

Predictable edges make a friendlier API

Clients can distinguish an empty answer, a bad request and a busy public route.

200

Readable result

JSON response or a successful empty collection.

404

No retained sample

Some single-resource reads have nothing to return yet.

400

Outside the contract

Unsupported corridor, timestamp, window or limit.

429

Slow the polling loop

Per-minute public limit exceeded; honor Retry-After.

Built-in guardrails

Useful access without accidental provider spend.

  • Bounded readsHistory requires a corridor and controlled window or limit.
  • Retained data onlyThese reads do not trigger new TomTom or CDOT requests.
  • Private stays privateCredentials and operational secrets are never returned.

Time fields use ISO 8601 UTC. For data meaning and historical boundaries, read About the Data. DTOs and validation live in the API service source.
