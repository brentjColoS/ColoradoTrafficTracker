Pipeline 01

Traffic speeds

  1. Request data within the TomTom source budget
  2. Decode provider road data
  3. Keep only the tracked corridors
  4. Project speeds onto the monitored roadway
  5. Store and update stable 0.5-mile road sections

Each successful collection refreshes the current corridor picture while retained snapshots build history.

Pipeline 02

Road incidents

  1. Read the latest CDOT report
  2. Keep reports on tracked mile markers
  3. Use clear categories, status and locations
  4. Match the same incident across updates
  5. Publish only a complete checked snapshot

An incident keeps its history across updates.

A failed or incomplete update does not replace the last complete report.

What the states mean

Healthy
Both corridors have recent usable speeds, CDOT reports are fresh, and the traffic source is reporting normally.
Degraded
The site can still show traffic, but at least one named check is late or unavailable.
Out of service
No monitored corridor has recent usable speeds. One unavailable TomTom account is not an outage while another can continue.

Background monitoring

The server reports externally twice daily. It allows one hour for traffic and CDOT freshness, warns after eight days without an off-site backup, and warns at 10 GB of available disk space.

Every warning includes what happened and a next action.
