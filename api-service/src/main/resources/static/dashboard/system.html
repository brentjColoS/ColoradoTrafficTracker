What the states mean

Healthy
Both corridors have recent usable flow, CDOT snapshots are fresh, and the provider guard is reporting normally.
Degraded
The site can still serve traffic data, but at least one named check is outside its expected threshold.
Out of service
No monitored corridor has recent usable flow. One exhausted TomTom account is not enough to produce this state while another account can ingest.

Background monitoring

The server sends a low-maintenance external health report twice daily. It allows one hour for current flow and CDOT snapshots, warns when an off-site backup is more than eight days old, and warns at 10 GB of available server disk space.

Every warning includes the failing component, observed condition, and a suggested next action.
