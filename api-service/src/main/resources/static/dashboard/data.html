Sources and interpretation

About the data

Colorado Traffic Tracker combines live road-flow observations with Colorado roadway incident reports, then keeps the useful history available for comparison.

Monitored corridors

I-25 Front Range
Mile markers 208–271.
I-70 Mountain Corridor
Mile markers 206–259.

These boundaries apply to flow maps and CDOT incident filtering. Reports outside them are not presented as corridor incidents.

Traffic flow

TomTom flow observations are collected on a schedule and retained as corridor and speed-zone time series. The dashboard distinguishes a new observation from a repeated value because stable traffic can legitimately produce the same speed.

The focused map groups retained half-mile cell identities into readable one-mile display intervals. The source can span more than one interval, so the line is a combined-direction view—not a claim of independent per-mile or per-direction sensing.

Incidents

CDOT reports are filtered to the tracked highway and mile-marker ranges. Durable event identity preserves first seen, last seen, current status, type, lane impacts, and useful provider details without copying the same event into every traffic sample.

Observed duration is the time between retained sightings. It is not necessarily the exact real-world start or clearance time.

Derived views

  • Trend lines smooth the retained observations; they are not additional measurements.
  • The reference band is built from comparable historical weekday and time observations.
  • Estimated travel time sums distance divided by current speed across the combined-direction half-mile intervals. It falls back to the current corridor average when complete interval coverage is unavailable.
  • Fastest and slowest travel times today compare the current estimate with hourly corridor estimates since midnight in Denver. The range starts over after midnight on the next dashboard refresh.
  • Long-range map colors show how often slowdown conditions occurred, not the speed at one historical instant.

History and coverage

Older corridor samples remain queryable after they move from the live table into archive storage. Detailed speed-zone rows became durably retained through a later migration, so their earliest available date can differ from corridor-level history. Durable map-cell history begins at 2026-09-24T21:00:00Z.

The exact durable speed-zone boundary is still being verified while the broader history documentation is reworked. The repository’s data history coverage note is the source of truth for that boundary.
