Source layer

Two sources answer different questions

Traffic is observed. Incidents are reported. The interface keeps that distinction intact.

Traffic flow

How fast is the road moving?

Scheduled TomTom observations become corridor, speed-zone and half-mile traffic history.

Provides
current and free-flow speeds with road geometry
Does not imply
an independent sensor in every direction or every mile
Roadway reports

What has been reported on the road?

CDOT incidents and planned events are filtered to the tracked corridor and mile-marker bounds.

Provides
type, status, location, lane impact and provider detail
Does not imply
an exact real-world start or clearance time

Reading the dashboard

Four words carry most of the meaning

These labels are deliberately different; swapping them would overstate the data.

Observed

A source was successfully read.

An unchanged value can still be a fresh observation.

Current

The newest usable retained state.

Freshness is based on observation time, not whether speed changed.

Estimated

A transparent calculation.

Travel time is useful context, not a measured end-to-end trip.

Baseline

A comparable historical pattern.

It matches weekday and time instead of using a generic average.

Derived views

Useful math, shown with its recipe

Each view is built from retained observations; none creates a new measurement.

Reference band

Like-for-like history

The rolling profile uses the preceding 13 completed weeks and matches the same Denver weekday and hour. The band describes variation, not certainty.

Long-range map

Frequency, not one instant

History and coverage

Older does not mean discarded

Retention moves data into queryable history. It does not erase it to make the live tables smaller.

01Live observations

Current corridor, zone, incident and map state.

02Queryable archive

Older corridor samples remain in the same history reads.

03Dataset boundaries

Detailed zone history starts later than corridor-level history.

04Map-cell history

Durable coverage begins September 24, 2026 at 21:00 UTC.

Detailed speed-zone history has a later boundary. Until its exact production start is confirmed, the oldest returned row is the practical availability limit. The coverage note records the latest verified detail.

Interpretation contract

Clear limits are part of the product.

  • Combined directionTraffic flow is a combined-direction view, not independent directional sensing.
  • Observed durationIncident timing reflects retained sightings, not a guaranteed real-world clock.
  • Visible gapsMissing collection periods stay missing instead of being joined into a confident line.
