Source layer

Two sources answer different questions

Traffic is observed. Incidents are reported. The interface keeps that distinction intact.

Traffic flow

How fast is the road moving?

Scheduled TomTom observations become corridor, speed-zone and half-mile traffic history.

Provides
current and free-flow speeds with road geometry
Does not imply
an independent sensor in every direction or every mile
Roadway reports

What has been reported on the road?

CDOT incidents and planned events are filtered to the tracked corridor and mile-marker bounds.

Provides
type, status, location, lane impact and provider detail
Does not imply
an exact real-world start or clearance time

Reading the dashboard

Four labels tell you where a number came from

Use the label beside a value to tell whether it came from a source, a check, a calculation or matched history.

Observed

Read directly from a source.

TomTom or CDOT was successfully read at the time shown. A repeated value can still be a new reading.

Current

The latest reading that passed our checks.

“Current” is based on when it was observed—not whether the speed or incident changed.

Estimated

Calculated from observed speeds.

Travel time adds the road sections together. It is not a measured end-to-end trip.

Baseline

Matched with similar moments in history.

The same weekday and hour from the previous 13 completed weeks—not a generic average.

Interpretation limits

Clear limits are part of the product.

These three limits stay visible so an estimate is not mistaken for a direct measurement.

Combined directionTraffic flow is a combined-direction view, not independent directional sensing.
Observed durationIncident timing reflects retained sightings, not a guaranteed real-world clock.
Visible gapsMissing collection periods stay missing instead of becoming a confident line.
